# 2026-11-18 工作日志

## 聚焦(关灯)功能五项修复(2026-11-18 凌晨)
- **用户反馈五项问题**:①聚焦菜单(关灯/放大/插入白板/保存/关闭)固定在底部居中,应跟随矩形框;②关灯默认高亮(不该);③点关灯无效果;④"放大"应是矩形框内内容放大(像放大镜),不是放大框本身;⑤保存点击无效。
- **根因与修复(SpotlightLayer.tsx 重构)**:
  1. **菜单跟随框**:菜单从 `position:fixed bottom:90 left:50%` 改为 `position:absolute`,坐标按 rect 计算——优先放框下方(rect.y+rect.h+GAP),空间不足放框上方;水平居中于框(menuLeft 钳制屏幕边界)。
  2. **关灯默认不高亮**:状态从 `zoomed:boolean` 改为 `mode:'off'|'magnify'`(默认 off)。关灯按钮**不设 active**(默认态不高亮);放大按钮 `active={mode==='magnify'}` 仅在放大镜模式高亮。
  3. **关灯点击有效**:关灯按钮 `setMode('off')+setMagnifyImage(null)`,从放大镜切回关灯态(遮罩挖孔透出桌面)。
  4. **放大=放大镜**:新增 `onCapture(rect)` prop。点击放大→`enterMagnify` 截取当前框内容(desktopCapturer)→框内叠加 `overflow:hidden` 容器 + `<img>` 用 `transform:scale(2) + transformOrigin:center` 放大显示(中心内容放大、边缘裁切),矩形框本身不动。框移动/缩放松手时(`onPointerUp`)在 magnify 模式重新截屏刷新。
  5. **保存无效**:两处根因——(a)`dialog.showSaveDialog(mainWindow!)` 把 `focusable:false + type:'toolbar'` 的悬浮窗口作 parent,模态对话框无法弹出;改为**不传 parent**。(b)截屏会把悬浮窗口自己的遮罩/挖孔框/蓝框/手柄一并截入,导致"插入白板/保存/放大"截到脏画面。
- **主进程 index.ts 修复**:
  - `captureScreenRect`:截屏前 `mainWindow.hide()` + 等 120ms(DWM 移除窗口画面)→ 截屏 → `finally` 里 `showInactive()+setFocusable(false)` 恢复(不抢前台焦点)。所有截屏(insert/save/magnify)均获干净桌面内容。
  - `spotlight:save` 的 `dialog.showSaveDialog` 去掉 parent 参数。
- **TeacherWorkspace**:SpotlightLayer 传 `onCapture={(rect)=>api.spotlight.capture(rect)}`。
- **技术要点**:框 div 不设 overflow:hidden(否则裁掉 -5px 手柄),放大图容器单独 overflow:hidden;`rectRef` 始终同步最新 rect 供指针事件闭包读取(避免 setState 闭包过期);放大截屏用 `capturingRef` 防抖。
- 验证:teacher tsc 全净(0 错)。

## 「窗口」面板实装:枚举系统窗口 + 切前台(2026-11-18)
- **需求**:Dock 栏「窗口」导航项原本只弹占位面板(写死"C30 教师端/超级白板")。用户澄清:应是**系统真实窗口列表**(代替底部任务栏),点击把选中窗口**提到前台**。
- **实现(主进程 index.ts 新增 `registerWindowList`)**:
  - `windows:list`:用 `desktopCapturer.getSources({types:['window']})` 枚举窗口。Windows 上 source.id 形如 `window:<hwnd>:0`,用正则提取十进制 HWND。过滤:空标题、自身悬浮窗(用 `mainWindow.webContents.getMediaSourceId(mainWindow.webContents)` 精确匹配 + 标题兜底)、缩略图 <8px 的系统小窗(任务栏/托盘)。返回 `{id,title,hwnd,thumbnail}`(缩略图 160×100 物理像素 dataURL)。
  - `windows:activate`:走 PowerShell `Add-Type` 调 user32——先 `IsIconic`+`ShowWindow(hwnd,9)` 还原最小化窗口,再 `keybd_event` 模拟 Alt 抬起(绕过 Windows 前台锁:悬浮窗 focusable:false 永不抢占前台,直接 SetForegroundWindow 会被拒),最后 `BringWindowToTop`+`SetForegroundWindow`。`execFile` 8s 超时。
  - `app.whenReady` 里注册 `registerWindowList()`。
- **preload**:新增 `windows.list()` / `windows.activate(hwnd)`。
- **FloatingDock.tsx**:窗口面板改为真实列表——「回到电脑桌面」按钮(保留)+ 「已打开的窗口」标题 + 刷新按钮(带 spin 动画)+ 缩略图卡片列表(64×40 缩略图 + 单行标题省略),点击激活窗口后**收起面板**(任务栏式交互)。打开面板时 `useEffect` 触发 `refreshWindows()`。
- **global.css**:新增 `@keyframes spin`(刷新转圈)。
- **技术要点**:Electron 无"激活任意系统窗口"原生 API,故枚举用 desktopCapturer、激活用 PowerShell+user32(不新增原生模块);`getMediaSourceId` 在 Electron33 需传参 `requestWebContents`(有效期 10s,枚举同步对比)。
- 验证:teacher tsc 全净。

## 「菜单」→ 系统设置面板(开机自启/教室信息/互动开关)(2026-11-18)
- **需求**:Dock 栏底部「菜单」按钮点击后打开设置面板,展示三项系统设置:①开机自启 ②是否展示教室信息(右上角状态条)③是否允许互动(关闭时底部「互动」按钮置灰+点击弹黑色 toast"互动功能已被关闭")。
- **持久化(主进程 index.ts 新增 settings 模块)**:

  - 开机自启副作用:`app.setLoginItemSettings({openAtLogin})`(Windows 写注册表 Run 项)。
- **preload**:新增 `settings.get()` / `settings.set(patch)`。
- **TeacherWorkspace.tsx**:提升 `appSettings` state(默认值)+ `updateSettings`(乐观更新+调 api.settings.set)+ 启动 `useEffect` 拉取。TopStatusBar 显隐条件加 `appSettings.showClassInfo`;BottomToolbar 传 `allowInteraction={appSettings.allowInteraction}`。
- **FloatingDock.tsx**:
  - props 增 `settings` / `onSettingsChange`。
  - 菜单面板从"身份/网络/在线人数"改为「系统设置」面板:标题 + `{name}·发送端·N人在线` 副标题 + 三个 `SettingRow` 开关(自定义带说明文字的 iOS 式滑块)+ 「退出」按钮(保留)。
  - `SettingRow` 新组件:label+desc+44×24 滑块开关。

- **技术要点**:设置面板 div 加 `data-interactive` 保证鼠标不穿透可点;遮罩 inset:0 在面板打开时锁定穿透(modal 式);`networkStatus` prop 在 FloatingDock 主组件已不再使用(仅 TopStatusBar 用)。
