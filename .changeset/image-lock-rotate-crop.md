白板图片加工:锁定 / 旋转 / 裁剪,置顶改为放到笔迹之上

- 恢复「按下即可选中并可拖动」:点中图片就是选中,按住就能拖(锁定后除外)
- **锁定 / 解锁**:锁定后定位框与手柄变红、拖不动,再点一次解锁
- **旋转**:顺时针 90°,绕图片中心,宽高互换
- **裁剪**:虚线裁剪框 + 三分线 + 四角手柄,「取消 / 确定」;确定后按比例裁出真实像素
- **置顶 / 取消置顶**:置顶后图片渲染在笔迹之上(会盖住已有笔迹),取消后回到笔迹之下;
  学生端同步看到同样的层序
- 旋转/裁剪是就地烘焙成新位图(顺带更新位置尺寸),命中测试与两端渲染都保持简单;
  锁定 / 旋转 / 裁剪 / 置顶全部进撤销栈,可连同位图一起撤销重做
