课堂按「上课 / 下课」控制画面推送,学生可提前进入房间等待

- 房间与上课拆成两个生命周期:老师启动即建好房间,mDNS 可被发现,学生能提前进入等待
- 老师点「上课」后服务端广播 `class.state`,学生端才从等待页切到跟随画面;点「下课」立即停止推送并退回等待页
- 未上课时白板笔迹 / 图片只存服务端不广播,上课时一次性补发完整快照(含课前准备的板书);学生提前进课堂不会看到课前内容
- 学生端新增等待页(老师名字 / 房间号 / 在线人数 / 退出课堂),等待与下课后不锁定桌面,只有上课中才全屏跟随
