课堂互动落地:互动面板(随机点名 / 抢答 / 举手 / 投票 / 观点云 / 计时),两端实时联动

- 教师端底部「互动」不再是点了没反应的按钮:点开是功能菜单,发起后自动切到结果页(投票实时柱状图、
  抢答名次、观点云词云、点名确认、课堂倒计时),结束后保留结果供讲评
- 学生端有对应的真实入口:被点名卡片与「我知道了」、抢答按钮与名次、投票/观点云作答(可改)、
  右下角常驻举手按钮、顶部同步倒计时
- 服务端(内嵌课堂服务器)维护互动状态:只有教师能发起/结束,限时到点自动结束,抢答只认第一次,
  迟到学生挂载时补拉快照,学生掉线清理举手,下课后清空互动
- 设置里的「允许互动」成为总开关:关闭即清空进行中的互动,学生端隐藏互动入口
- 协议:`packages/shared` 新增 `interact.ts`(InteractSnapshot / start / respond / hand / end / reset / pick / sync);
  `InteractionControl` 的 `quizEnabled` 收敛为 `interactEnabled`
