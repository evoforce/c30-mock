# @c30/shared

## 0.2.0

### Minor Changes

- 71a85c8: 浮层交互重做:全块拖拽、入场动画、画笔颜色盘、板擦收敛为自由擦除

  - **拖动**:浮层上不再有任何拖拽把手/图标(侧边竖条顶部短横、底部工具条左端竖条、收起箭头下的两道短横全部移除),
    但拖动能力保留并升级为**整块任意位置可拖** —— 面板上任意一点按下都能拖,位移 < 5px 仍算点击,
    ≥ 5px 才进入拖动并吞掉松手后的那次 click,不会「拖完顺手点开一个功能」
  - **入场动画**:浮层展示时按所贴屏幕边从外向内滑入 + 淡入(贴右从右进、贴左从左进、贴底从下进),
    侧边竖条、贴边箭头、底部工具条、画笔/板擦菜单、设置与窗口面板全部接入;用独立的 `translate`
    属性做位移,不覆盖浮层自身的居中 `transform`;系统开启「减少动态效果」时动画自动缩短
  - **画笔/板擦操作条**:只保留 撤销 / 重做 / 清空,移除「完成」
  - **画笔颜色盘(新增)**:颜色行最后一枚彩虹色块不再是占位,点击展开真正的颜色盘 ——
    圆盘选色相/饱和度(所见即所选)、右侧竖条调明暗、实时预览色值,拖动即时改画笔颜色
  - **板擦**:移除「清笔迹 / 区域擦除」选项,擦除语义固定为**自由擦除**(涂到哪擦到哪);
    大小 4 档上调为 24/36/52/72(默认 36),最小档也足够大;面板文字统一改用浅灰/白,
    修复按钮默认深色文字在黑色面板上看不清的问题
  - `@c30/shared` 移除已无意义的 `EraserMode` 类型

- ebb898d: 白板图片可选中编辑:移动 / 缩放 / 置顶 / 复制 / 删除(可撤销)

  - 聚焦「插入白板」贴进来的截图现在可以在「选择」工具下点选:蓝色选框 + 8 个手柄,
    拖动即可移动、拖手柄缩放(四角等比、四边自由,最小 24px)
  - 选中后浮出操作条:**置顶 / 复制 / 删除**;也支持键盘 Delete / Backspace 删除、Esc 取消选中
  - 图片叠放改用 `z` 排序(不再依赖数组顺序),`shared` 新增 `ImageItem.z` 与 `sortImagesByZ`;
    协议新增 `image.update`,教师端拖动时以 20fps 节流同步、松手补发最终值,学生端实时跟随
  - 图片操作全部记入与笔画共用的一套撤销栈:删除/复制/置顶/移动/缩放都能「撤销 / 重做」
  - 「清空」只清笔迹,不会误删底图

  验证:五个包 tsc --noEmit 全净,teacher/student electron-vite build 通过;
  用 Electron 探针真渲染白板并驱动真实鼠标:点选出现操作条、拖动移动 +100/+60、
  右下角手柄 300×200 → 360×240(保持 1:1.5)、置顶后 DOM 顺序切换、键盘删除、撤销后原图连尺寸一起复原。

### Patch Changes

- 659c974: 白板擦升级:矩形板擦 + 按住拖动自由擦除 + 高级菜单(清笔迹 / 区域擦除)

  - 板擦改为**矩形**(宽 = 2 × 半径,高 = 宽 × 0.72),预览样式与实际擦除区域完全一致
    (所见即所擦);且**只在鼠标按下时出现**,松开立即消失
  - **自由擦除**:按住拖动连续擦除,把「上一位置 → 当前位置」按细步长(≤ 短边 / 6,且 ≥ 1.5px)
    细分成一串互相重叠的矩形,即使鼠标事件稀疏也不会「跳着擦、漏一段」
  - **区域擦除(新增)**:像画笔一样涂抹,只把与板擦**相交的部分**裁掉,剩余部分切成多条笔迹片段
    (沿用 `stroke.remove` + `stroke.append` 协议,学生端无需改动)
  - **清笔迹**:碰到笔迹即整条删除,适合快速清场;两种方式在「板擦」高级菜单里一键切换
  - **撤销粒度**:一次擦除手势(按下 → 抬起)合成一步撤销,区域擦除切出的片段也能整段还原
  - 板擦面板同步升级:大小 4 档改为矩形预览,新增「擦除方式」选择与操作提示

- 183c672: 修复聚焦「保存」后浮层整体点不动、聚焦「插入白板」图片盖住笔迹的问题，并升级浮层交互

  - 聚焦保存：不再使用原生「另存为」对话框（Windows 上该原生模态窗口关闭后会让这个透明、
    `WS_EX_NOACTIVATE` 的浮层窗口丢失鼠标「按下」事件——mousemove 仍能收到，但底栏、收起、
    侧边栏全部点不动，只能重启），改为直接保存到「图片/C30 聚焦/聚焦\_<时间戳>.png」并在浮层内提示
  - 聚焦插入白板：截图改为底图（图片层移到 canvas 之前，canvas 显式 `position: relative`），
    画笔/板擦可正常覆盖在图片上方；教师端本地插入底图（服务端只把事件转发给其他客户端），
    白板快照按 id 合并，避免刚插入的底图被快照覆盖
  - 鼠标穿透：穿透状态只保留一份真源，主进程按鼠标位置主动同步 + `elementFromPoint` 判定悬停，
    不再依赖 `forward` 的 mousemove 转发
  - 浮层体验：新增 `useOverlayScale` 按屏幕尺寸等比缩放、`EraserPanel` 板擦面板与
    `EraserMode`（清笔迹 / 区域擦除），教师端与学生端白板同步

- 8aa06e3: 初始化 C30 monorepo 骨架:根配置(pnpm + turbo + changesets)、共享包、NestJS 后端、Electron 双端(vite-electron)、C++ 白板核心、docker-compose 与数据模型。
